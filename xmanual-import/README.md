# Xmanual 图片批量导入包

按用户截图的“图片管理 → 批量导入”格式制作。每份ZIP根目录包含 `resource.xlsx` 和 `resource/` 文件夹；Excel六列依次是名称、编号、文件、格式、语言、备注。

- [中文版图片导入包](Xmanual_Images_Chinese.zip)：语言字段 `zh-CN`。
- [英文版图片导入包](Xmanual_Images_English.zip)：语言字段使用常见代码 `en-US`；截图未展示英文代码说明，若网站拒绝该值，按实际错误或指南调整。

下载后不用解压，在Xmanual“批量导入”窗口点“点击上传”，选择对应ZIP。上传后仍需在手册编辑中插入需要的图片。

三张图片均为AI概念示意，限制已写入备注。产品概览、场景与充电概念图不替代官方部件或操作图。网站导入尚未实际测试；本地已检查ZIP完整性、Excel结构和全部图片路径。
